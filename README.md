## **Addressable 소개**

### **1. Addressables는 무엇인가?**

- Addressables는 Unity에서 **에셋을 효율적으로 로드하고 관리하기 위한 시스템**

- 모든 리소스에 **주소(Address)를 부여하여 필요한 시점에 원하는 리소스를 동적 로드/언로드할 수 있음.

- 기존 **Resources 폴더 기반 로딩 방식의 차세대 대안**

```cs
Resources.Load<GameObject>("경로/파일명");
Resources.LoadAll<AudioClip>("경로");
```

## **2. 왜 Addressables를 사용해야 하는가?**

### **1) 메모리 최적화**
전체 리소스를 한 번에 메모리에 올릴 필요가 없고,**필요한 순간에만 불러와 사용 후 언로드**할 수 있어 메모리 사용량을 크게 줄일 수 있습니다.

### **2) 빌드 크기 관리**
AssetBundles 기반으로 동작하므로 **필요한 리소스만 빌드**하거나, 플랫폼별로 **번들 분리·관리**가 수월합니다.

### **3) 라이브 서비스 업데이트에 최적화**
서버(원격 CDN)에 올린 Addressables 번들을 교체하는 방식으로 **앱 재배포 없이 리소스 업데이트**가 가능합니다.

– 새로운 캐릭터 추가
– 밸런스 조정용 데이터 테이블 교체
– 이벤트 리소스 다운로드 등
